# 水深反演混合系统项目总结

## 项目概述

本项目旨在开发一个**混合水深测量系统**，用于更精确和高效地进行水深反演（Satellite-Derived Bathymetry, SDB）。该系统结合了**经典机器学习模型 (随机森林)** 和**先进的时空生成扩散模型 (S3GM)**，并融合了 Sentinel-2 影像、GEBCO 全球水深数据和稀疏海图测量点，成功实现了高精度的水深预测。

项目代码主要位于 `bathymetry/` 目录下，核心执行脚本为 `run_bathymetry.py`。模型训练和预测流程被划分为多个阶段，方便用户根据需求执行特定的处理步骤。

## 研究目的与成果

本研究的核心目的是**利用先进的生成模型提升遥感水深反演的精度和空间连续性**。传统的水深反演方法在精度和处理复杂水体环境方面存在局限。本项目引入了**时空生成扩散模型 (S3GM)**，利用其强大的时空建模和数据融合能力，显著改善了传统模型的性能。

**主要成果:**

1.  **成功应用 S3GM:** 首次将 S3GM 模型（一种先进的扩散模型）应用于复杂的多源卫星遥感水深反演任务。
2.  **实现高精度预测:** 通过结合经典模型（随机森林）的初步预测、GEBCO 先验数据和稀疏海图观测点作为 S3GM 的条件引导，最终模型在验证集上取得了优异的性能 (R² ≈ 0.937, RMSE ≈ 3.19m, MAE ≈ 2.55m)，远超单一经典模型。
3.  **提升空间连续性:** 相比传统模型（如随机森林）生成的噪声化结果，S3GM 生成的水深图具有明显更好的空间平滑度和连续性，更符合真实地理场景。
4.  **关键参数敏感性分析:** 通过系统性实验，揭示了扩散模型超参数（特别是 SDE 参数 `beta_max`、数据拟合权重 `alpha`、空间平滑权重 `gamma_spatial`）对模型性能和稳定性的关键影响，为后续研究提供了重要参考。
5.  **多源数据融合框架:** 构建了一个有效融合多时相 Sentinel-2 影像、GEBCO 数据和稀疏高精度海图测点的混合模型框架。

## 数据利用策略

本项目充分利用了以下数据资源：

1.  **Sentinel-2 影像 (2018-2023):**
    *   利用 GEE 获取 L2A 影像，主要使用蓝、绿波段。
    *   通过 MIWC (`miwc.py`) 进行水柱校正预处理。
    *   作为经典模型输入和 S3GM 的间接输入（通过经典模型预测结果）。

2.  **GEBCO 全球水深数据 (2019-2024):**
    *   作为先验水深信息，输入 S3GM。
    *   经过预处理 (`bathymetry/preprocessor.py`) 与标准化，和 Sentinel-2 对齐。

3.  **官方航海海图数据 (`Official_nautical_chart/`):**
    *   提供稀疏但高精度的水深测量点。
    *   作为经典模型的训练目标。
    *   作为 S3GM 条件采样的**核心观测约束**。
    *   作为最终模型性能验证的**基准真值**。

4.  **经典机器学习模型 (随机森林) (`bathymetry/classic_models.py`):**
    *   使用 Sentinel-2 蓝、绿波段和海图数据训练。
    *   其预测结果作为 S3GM 的**重要输入特征之一**，构成混合模型的关键部分。

5.  **S3GM (Spatio-Temporal Generative Model) (`S3GM/`):**
    *   核心模型，基于 UNetVideoModel 架构和 VPSDE 扩散过程。
    *   通过条件采样机制 (`sampler/utils.py` 中的 `complete_video_pc_dps`) 融合经典模型预测、GEBCO 数据和海图稀疏点。
    *   利用数据拟合项 (`alpha` 控制) 和空间平滑项 (`gamma_spatial` 控制) 进行引导。
    *   模型配置文件 `configs/s3gm_default.yaml`，包装器 `bathymetry/s3gm_wrapper.py`。

6.  **陆地/水体掩码 (来自 JRC Global Surface Water):**
    *   用于 Stage 3 可视化，叠加显示陆地轮廓，提升地图可读性。

## 总结与展望

本项目成功构建并验证了一个基于 S3GM 的高精度混合水深反演系统。实验证明，通过精心设计的数据融合策略和细致的超参数调整，扩散模型在处理复杂的地球科学反演问题上具有巨大潜力。当前系统在 64x64 分辨率下表现优异，下一步的关键挑战是提升空间分辨率，以生成更精细、视觉效果更佳的水深产品。
