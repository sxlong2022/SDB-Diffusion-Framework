# 水深反演混合系统项目总结

## 项目概述

本项目旨在开发一个**混合水深测量系统**，用于更精确和高效地进行水深反演（Bathymetry）。该系统结合了**经典机器学习模型**和**先进的生成扩散模型 (S3GM)**，并融合了多种数据源，以期提高水深预测的准确性和可靠性。

项目代码主要位于 `bathymetry/` 目录下，核心执行脚本为 `run_bathymetry.py`。模型训练和预测流程被划分为多个阶段，方便用户根据需求执行特定的处理步骤。

## 研究目的

本研究的核心目的是**提升遥感水深反演的精度**。传统的水深反演方法，如基于波段比值的经典模型，在特定条件下存在局限性。本项目引入了**时空生成扩散模型 (S3GM)**，旨在利用其强大的时空建模能力，结合多种辅助数据源（GEBCO 全球水深数据、海图稀疏测量点），来**改善传统模型的不足**，并生成更高质量、更可靠的水深预测结果。

具体目标包括：

1. **融合多源数据**：有效整合 Sentinel-2 卫星影像、GEBCO 全球水深数据以及官方海图的稀疏测量数据。
2. **利用经典模型**：构建并训练经典的机器学习模型（如随机森林），作为 S3GM 模型的输入特征之一，并进行初步的水深预测。
3. **应用 S3GM 模型**：将 S3GM 模型应用于水深反演，利用其时空建模能力，提升预测精度和空间连续性。
4. **模型验证与评估**：通过与官方海图数据对比，对经典模型和 S3GM 模型的预测结果进行定量评估和可视化分析。

## 数据利用策略

本项目充分利用了以下数据资源：

1. **Sentinel-2 卫星影像**：
    -  使用 Google Earth Engine (GEE) 平台获取研究区域的 Sentinel-2 L2A 影像。
    -  主要利用**蓝色和绿色波段**数据，这些波段对水体穿透性较好，与水深信息相关性高。
    -  使用 **MIWC (多尺度图像水柱校正)** 方法 (`miwc.py`) 对 Sentinel-2 影像进行预处理，以减少水柱效应的影响。
    -  时间序列 Sentinel-2 影像 (2018-2023) 被用于训练经典模型和作为 S3GM 模型的输入。

2. **GEBCO 全球水深数据 (2019-2024)**：
    -  GEBCO 数据作为**先验水深信息**，为模型提供初始的水深估计。
    -  GEBCO 数据经过**预处理和标准化** (`bathymetry/preprocessor.py`)，与 Sentinel-2 影像进行空间对齐。
    -  时间序列 GEBCO 数据 (2019-2024) 也被用作 S3GM 模型的输入。

3. **官方航海海图数据** (`Official_nautical_chart/`)：
    -  海图数据提供**稀疏但高精度的水深测量点**，作为**训练和验证数据**。
    -  海图数据经过预处理，提取**深度值和地理坐标**，并转换为归一化坐标。
    -  海图数据用于训练经典模型，并在模型验证阶段作为**真实水深值**，评估模型性能。

4. **经典机器学习模型** (`bathymetry/classic_models.py`)：
    -  本项目训练了**随机森林 (Random Forest)** 经典模型，以及**线性回归模型** (虽然 `run_bathymetry.py` 中主要使用了随机森林)。
    -  经典模型使用 Sentinel-2 的**蓝色和绿色波段**作为输入特征，海图数据作为训练目标。
    -  经典模型的**预测结果**被进一步用作 **S3GM 模型的输入**，构成混合模型的关键组成部分。

5. **S3GM (Spatio-Temporal Generative Model)** (`S3GM/`)：
    -  S3GM 模型是本项目的核心模型，利用**扩散模型**的强大生成能力，进行时空水深反演。
    -  S3GM 模型**融合了经典模型的预测结果、GEBCO 数据和海图稀疏测量点**，进行条件采样，生成最终的水深预测结果。
    -  S3GM 模型的配置文件为 `configs/s3gm_default.yaml`，模型包装器代码位于 `bathymetry/s3gm_wrapper.py`。


总而言之，本项目搭建了一个较为完整的水深反演混合系统框架，成功地将 S3GM 模型应用于遥感水深反演任务。
