# 项目目标: 基于GEE和Python复现MIWC方法并应用于舟山岛屿水深反演

**项目描述:**

本项目的目标是使用Python编程语言，结合Google Earth Engine (GEE) 平台，复现论文中提出的“多时相图像加权合成（Multi-temporal Image Weighted Composition, MIWC）方法”，并将该方法应用于中国舟山群岛某特定岛屿周围浅海水域的水深反演。项目将利用近六年该水域的水深实测数据进行模型验证和精度评估。

**任务分解:**

请生成一个Python项目框架，包含以下核心模块和功能：

1. **数据获取 (data_acquisition.py):**

    * 定义舟山目标岛屿的地理范围 (提供一个示例坐标范围，如经纬度边界框)。
    * 根据时间范围 (近六年) 筛选并获取 Sentinel-2 L1C 或 L2A 级影像数据。
    * 提供选项下载筛选后的影像元数据信息。
    * 提供函数加载本地已有的水深实测数据 (假设数据格式为CSV或GeoJSON，包含经纬度和深度信息)。

2. **数据预处理 (preprocessing.py):**
    * 对获取的Sentinel-2影像进行大气校正 (可选使用 Sen2Cor 或 GEE 自带的大气校正方法)。

3. **MIWC方法实现 (miwc.py):**
    * 实现论文中描述的 MIWC 方法，包括以下步骤：
        * **负值像素掩膜:**  对预处理后的影像进行负值像素的识别和掩膜。
        * **迭代阈值分割:**  基于近红外 (NIR) 波段信息，使用迭代的Otsu阈值分割算法进行水体分割。
        * **计算共同分割阈值:**  计算多时相影像水体的共同分割阈值。
        * **计算NIR反射率下限:**  根据水体分割结果，计算每景影像的NIR反射率下限。
        * **多时相图像加权合成:**  根据公式计算每个像素的权重，并进行加权合成，生成高质量的合成影像。权重计算基于 NIR 波段反射率和论文中提到的幂参数 (假设用户可配置)。
        * **空值插值:**  对合成影像中可能存在的空值进行线性插值。
        * **均值滤波:**  对合成影像进行 3x3 的均值滤波，以平滑图像。

4. **水深反演模型 (bathymetry.py):**
    * 实现论文中提到的两种经验水深反演模型：
        * **对数转换线性模型 (LLM):**  使用蓝绿波段，实现深度与波段反射率的线性关系模型。提供模型参数训练函数。
        * **对数转换比值模型 (LRM):** 使用蓝绿波段，实现深度与波段反射率比值的关系模型。提供模型参数训练函数。
    * 提供使用合成影像和实测数据训练模型参数的函数。

5. **水深反演应用 (apply_bathymetry.py):**
    * 使用训练好的水深反演模型，对 MIWC 生成的合成影像进行水深反演。
    * 输出水深栅格数据 (GeoTIFF 格式)。

6. **精度评估 (evaluation.py):**
    * 使用预留的实测水深数据，评估不同方法 (最佳单景影像、MIWC合成影像) 水深反演的精度。
    * 计算并输出以下精度指标：均方根误差 (RMSE)、偏差 (Bias)、决定系数 (R²)。
    * 提供绘制散点图，对比实测水深和反演水深的函数。

7. **可视化 (visualization.py):**

        * 实测水深与反演水深的散点图。
        * 论文中提到的权重可视化结果 (可选)。

8. **主程序 (main.py):**
    * 整合以上所有模块，实现从数据获取到精度评估的完整流程。
